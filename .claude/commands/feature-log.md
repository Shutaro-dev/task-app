# /feature-log — 機能ログを更新

実装した機能を feature-log.md に記録する。

## 使い方

このコマンドを呼び出すと、今回の会話で実装した変更内容をまとめて feature-log.md に追記します。

## フォーマット

```markdown
## YYYY-MM-DD

### フロントエンド / バックエンド / 共通

#### 機能名
- 変更内容の箇条書き
- バグ修正の場合は原因と対処も記載
```

## 実行

feature-log.md を Read して現在の内容を確認し、今回の変更を日付とともに末尾に追記してください。
